Sistema de Chamados e Clientes (C)

Programa em linguagem C, que simula o cadastro de clientes e o controle de chamados de suporte da empresa criada pelo grupo. Desenvolvido para a disciplina de PROJETO DE EXTENSAO EM DESENVOLVIMENTO DE SOFTWARE ,porém, utilizando os conteúdos lecionados nas outras disciplinas. 

## Funcionalidades
| Opção | Descrição |
|:-----:|-----------|
| 1 | Cadastrar cliente (nome, telefone e e-mail) |
| 2 | Listar clientes |
| 3 | Abrir chamado vinculado a um cliente |
| 4 | Listar chamados |
| 5 | Filtrar chamados por status (aberto/fechado) |
| 6 | Fechar chamado |
| 0 | Sair |
