## Sistema de Chamados e Clientes (C)

Programa em linguagem C, que simula o cadastro de clientes e o controle de chamados de suporte da empresa criada pelo grupo. Desenvolvido para a disciplina de PROJETO DE EXTENSÃO EM DESENVOLVIMENTO DE SOFTWARE ,porém, utilizando os conteúdos lecionados nas outras disciplinas. 

## Funcionalidades
| Opção | Descrição |
|:-----:|-----------|
| 1 | Cadastrar cliente (nome, telefone e e-mail) |
| 2 | Listar clientes |
| 3 | Abrir chamado vinculado a um cliente |
| 4 | Listar chamados |
| 5 | Filtrar chamados por status (aberto/fechado) |
| 6 | Fechar chamado |
| 0 | Sair |

## Como executar

O programa pode ser executado online, sem instalar nada:

1. Acesse o [OnlineGDB](https://www.onlinegdb.com/online_c_compiler).
2. Cole o código do arquivo `sistema.c` no editor (confira se a linguagem selecionada é **C**).
3. Clique em **Run**.
4. Use o terminal que aparece na parte de baixo da tela para interagir com o menu.
